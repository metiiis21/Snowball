# Мои финансы v8 — Vercel Ready

Рабочая версия инвестиционного дашборда с серверным подключением к T‑Инвестициям.

## Что есть
- Тёмный адаптивный интерфейс для компьютера и iPhone.
- Портфель и ручные операции.
- Импорт CSV брокерского отчёта.
- Поиск инструментов через MOEX ISS.
- Серверная синхронизация T‑Инвестиций.
- Поддержка нескольких открытых брокерских счетов.
- Токен T‑Invest не попадает в браузерный JavaScript.

## Публикация на Vercel
1. Загрузите содержимое этой папки в GitHub-репозиторий либо импортируйте проект в Vercel.
2. В Vercel откройте проект → **Settings → Environment Variables**.
3. Добавьте переменную `T_INVEST_TOKEN` и вставьте туда read-only токен T‑Invest.
4. Выберите окружение **Production** (при необходимости также Preview).
5. Сохраните переменную и выполните Redeploy.
6. Откройте выданный адрес `*.vercel.app`.
7. В приложении откройте раздел **Портфель** и нажмите синхронизацию T‑Инвестиций.

Важно: `.env` и настоящий токен не добавляйте в GitHub.

## Локальный запуск
Требуется Node.js 20+.

```bash
npm install
export T_INVEST_TOKEN='ваш_read_only_токен'
npm run dev
```

После запуска откройте `http://localhost:4173`.

## Архитектура
- `src/` — React/Vite интерфейс.
- `server.mjs` — локальный сервер для разработки.
- `api/tinvest/[...route].js` — Vercel Function для production.
- `T_INVEST_TOKEN` — только server-side environment variable.
